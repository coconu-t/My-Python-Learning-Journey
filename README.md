# My-Python-Learning-Journey

## 项目简介
这是我的 Python 课程学习仓库。本项目主要记录了本学期我在课堂内编写的 Python 练习程序，旨在通过实际操作巩固 Python 基础知识，解决日常学习中遇到的代码编写问题，并记录我的编程成长轨迹。

## 文件说明
目前仓库中包含以下文件：

* `exercise_01.py`：模拟充值业务程序。主要功能是接收用户输入的金额，并在屏幕上打印出充值成功的交互提示。
* `exercise_02.py`：遗传身高预测程序。根据父母的身高，利用特定公式计算并输出预测的儿子身高。

## 代码说明
本仓库的代码主要使用了基础的输入输出函数以及数据类型的转换。以下为核心代码片段说明：

### 1. exercise_01.py 核心代码

主要使用了 `input()` 获取文本，以及 `print()` 进行字符串拼接输出。
```python
# 获取用户输入的充值金额
money = input("欢迎使用***充值业务，请输入充值金额： ")
# 拼接字符串并输出结果
print("充值成功，您本次充值:" + money + "元")
```

### 2. exercise_02.py 核心代码

```python
# 获取父母身高，并转换为浮点数(float)以便进行数学计算
dad_height = float(input("请输入父亲的身高： "))
mom_height = float(input("请输入母亲的身高： "))

# 利用公式计算，并将结果转换为字符串(str)进行拼接输出
print("预测儿子身高为： " + str((dad_height + mom_height) * 0.54))
```
